# בונה תל״א – תח״י

אפליקציית ווב בעברית למורים ולרכזים. מנחה בראיון קצר על תלמיד/ה ומפיקה טבלאות תל״א / תח״י מוכנות להגשה.

ממעבדת הניסויים של מרי גרבי בשיתוף שרון רז.

## הפעלה

פשוט לפתוח את `index.html` בדפדפן. אין שרת, אין התקנה, אין שליחת נתונים לשום מקום — הכול רץ במכשיר.
להרצה מקומית עם שרת: `powershell -ExecutionPolicy Bypass -File serve.ps1` ואז `http://localhost:5178`.

## מבנה

| קובץ | תפקיד |
|---|---|
| `index.html` | המסגרת, כל העיצוב, ובנק המטרות מוטמע בתוך `<script id="bank">` |
| `app.js` | כל הלוגיקה: רצף השאלות, בחירת המטרות, בניית הטבלאות, יצוא DOCX |
| `goals-bank.json` | עותק המקור של בנק המטרות (לעריכה נוחה) |

**חשוב:** האפליקציה קוראת את הבנק מתוך `index.html`, לא מהקובץ החיצוני.
אחרי עריכת `goals-bank.json` צריך להעתיק את התוכן מחדש לתוך התג `<script id="bank" type="application/json">`.

## איך נבחרות המטרות

1. בכל תת-תחום שנבחר, המורה מדרג/ת כל היגד: **חוזק · חלקי · קושי**.
2. היגד שסומן "חלקי" או "קושי" מפעיל את המטרות שהוא מופיע ב-`triggeredBy` שלהן.
3. נבחרת מטרה אחת לכל תחום — זו עם הניקוד הגבוה ביותר (קושי = 3, חלקי = 2, בונוס להתאמה לשכבת הגיל ולתת-התחום שנבחר).
4. **מטרה בלי קושי מתועד לא נבנית.** אם בתחום מסוים לא סומן קושי שמפעיל מטרה, מוצגת הודעה במסך התוצר ואפשר להוסיף מטרה ידנית מהמאגר.

אמות המידה נלקחות מ-`criteriaNumeric` לפי שכבת הגיל (א׳-ב׳ / ג׳-ד׳ / ה׳-ו׳ / ז׳-ט׳), ואם אין — מ-`criteria`.
עמודת הדרכים והאמצעים נפתחת תמיד במה שכבר עבד אצל התלמיד/ה, ונחתמת בשעות התמיכה שדווחו.

## תח״י או תל״א

נקבע לפי המסגרת שנבחרה: כיתה רגילה עם שילוב ← **תח״י**, חינוך מיוחד ← **תל״א**.

## יצוא Word

הקובץ נבנה בדפדפן כ-DOCX אמיתי (חבילת OOXML מינימלית, ZIP ללא דחיסה), בפריסה לרוחב ובכיווניות RTL מלאה. אין ספריות חיצוניות.

## שמירה

ההתקדמות נשמרת אוטומטית ב-localStorage תחת `tela.draft.v1`, כולל עריכות ידניות בטבלאות. במסך הפתיחה יופיע "המשך טיוטה שמורה".
